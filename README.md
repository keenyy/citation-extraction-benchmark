# Citation extraction benchmark

`cases.csv` indexes the 250 judgments. `references.csv` contains the answers for the original benchmark. Filter `source_type` to `case` for all 4,018 case citations or `academic` for the 624 academic references.

The original key and pipeline are preserved at [commit a3a84c7](https://github.com/keenyy/citation-extraction-benchmark/tree/a3a84c7419bdb474bda32e7c8947c82ab8ffa44a).
