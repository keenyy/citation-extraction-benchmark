# Revised citation pipeline snapshot

This directory contains the revised source, not a standalone benchmark runner. R106 updates academic detection for legal dictionaries, R107 adds handling for eligible parliamentary-library research papers, and R108 updates handling of the judgment’s own citation and of bare case names. Some paths require corpus data that is not supplied here. Internal discussion labels were omitted from source comments and docstrings without changing the extraction logic.

For the source snapshot associated with the original benchmark, use [commit `a3a84c7`](https://github.com/keenyy/citation-extraction-benchmark/tree/a3a84c7419bdb474bda32e7c8947c82ab8ffa44a/pipeline). No revised aggregate pipeline score is claimed here.
